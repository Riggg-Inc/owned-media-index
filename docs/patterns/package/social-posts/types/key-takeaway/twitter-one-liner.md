# Twitter One Liner

A Twitter/X one-liner distills one episode takeaway into a short, standalone statement. Use it when compression preserves meaning; choose a thread when essential context will not fit.

**Stage:** Package → Social Posts → Key Takeaway  
**Score:** 4  
**Evidence:** practitioner observation

## Platform

Twitter/X

## What It Is

A Twitter/X one-liner distills one episode takeaway into a short, standalone statement.

## When To Use

Use it when compression preserves meaning; choose a thread when essential context will not fit.

## Template

```
[One source-supported takeaway in a complete sentence]
[Optional verified source link if it fits]
```

## Quality Bar

- Name one idea the reader can understand without the episode.
- Check the wording and context against the source; keep qualifications that change its meaning.
- Make the practical step or question specific, not just “add value.”
- Verify names, quotations, mentions and links before publishing. Do not add confidential details.
- Keep this short-post version within 280 weighted characters, including any link; check it in the composer.

## Example

Illustrative example — advice from a fictional interview, not a measured outcome:

> Before adding questions to your next recorded interview, ask one better follow-up: “What happened next?” Use the answer to uncover the sequence behind the story.

## Prompt Template

Select the source passage first. Supply it with the audience and intended action, then use this prompt:

```
Write ONE standalone Twitter/X takeaway sentence. Keep essential context; if it cannot fit, recommend a thread rather than misrepresenting the source.

Inputs:
- Audience and the task they need help with: [who and what]
- Source excerpt with surrounding context: [paste permitted material]
- Exact quote and verified speaker, if quoting: [quote and name]
- Episode title and verified URL: [title and URL, or omit link]
- Practical action or question: [one action]

Requirements:
- Use only the supplied facts. Flag missing inputs instead of inventing them.
- Preserve the source meaning and distinguish advice from observed results.
- Keep paraphrases outside quotation marks.
- Return the post and a separate list of facts, quotes and links for a human to check.
- Do not insert confidential details or unverified mentions.
- Draft for a standard short post: at most 280 weighted characters, including links.
```

Check the draft against the source, fix any errors, and recheck before publishing. Adapt the wording to this platform rather than copying a different post unchanged.

[Official X character-counting guidance](https://docs.x.com/fundamentals/counting-characters) explains weighted characters and the 23-character URL count.
