# Twitter Thread

A Twitter/X thread breaks an episode topic into connected short posts, each advancing the explanation. Use it for a sequence needing more room than one post; close with one clear action.

**Stage:** Package → Social Posts → Thread Breakdown  
**Score:** 4  
**Evidence:** practitioner observation

## Platform

Twitter/X

## What It Is

A Twitter/X thread breaks an episode topic into connected short posts, each advancing the explanation.

## When To Use

Use it for a sequence needing more room than one post; close with one clear action.

## Template

```
[Opening post — the question and useful takeaway]
[Middle posts — one connected, supported point each]
[Closing post — one next action and episode link]
```

## Quality Bar

- Each post adds one distinct point supported by the episode.
- Keep the context or qualification needed to understand each point.
- Check each post in the composer, including links and numbering.
- Close with one clear action; do not repeat the CTA at every step.

## Example

**Illustrative thread, not a real episode transcript.**

1. “Before ending a remote recording, check the files while everyone is still available. Here is a short sequence.”
2. “Play a sample from each speaker. Listen for missing or distorted audio.”
3. “Confirm the recordings have finished saving. If something is missing, ask that participant to stay while you check.”
4. “Use the check at the end of your next session. Full walkthrough: [episode link].”

Replace these points with the sequence actually supported by your episode.

## Prompt Template

Start with the actual source passage, not only the episode title.

```
Create a connected Twitter/X thread from the source below.

Inputs:
- Intended reader and question: [reader + question]
- Episode title and public link: [title + verified URL]
- Source passage with speaker and timestamps: [paste relevant transcript]
- Public-use permissions and details to omit: [notes]

Output:
- Numbered posts: opening question, connected points, one closing action.
- Keep each ordinary short post within 280 weighted characters, including links and numbering.
- Give a source location for every quotation or substantive point in a separate review checklist.
- If the source lacks a needed fact, mark it missing; do not invent facts, steps or results.
- Keep any qualification that changes the meaning.
- Adapt the wording to this reader, not a copy of another platform post.
```

Before publishing, check each point against the recording, confirm names and links, and remove private or unapproved details. Fix mismatches and recheck; publish only when the remaining issues are resolved.

For ordinary short posts, [X counts weighted characters](https://docs.x.com/fundamentals/counting-characters), including 23 characters per URL; the composer is the final check.
