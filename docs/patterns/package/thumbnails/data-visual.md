**Score:** 3  
**Evidence:** platform observation

## What It Is

A thumbnail featuring a key statistic, chart element, or number as the primary visual. Works when the data point is the hook.

Start with one verified number from the episode. Keep its unit and timeframe in the image; if that context will not fit, choose another thumbnail style.

## Example

Illustrative layout: an episode explains a documented change from 12 days to 8 days. Use “12 → 8 days” as the main visual and “Shorter onboarding” as the small supporting line. Do not turn that example into a claimed result for your show.

## Quality Bar

- Readable at 120x120px minimum
- Maximum 5-7 words of text
- High contrast between text and background
- Brand colors consistent with show identity
- Face visible when using headshot or emotion styles

## When Not To Use

Avoid when the data point requires context to understand or when the number is not surprising.

## Prompt Template

Copy and customize this prompt to generate this pattern:

```
Create a thumbnail using the Data Visual pattern.

Context:
- Verified number, unit and timeframe: [exact values]
- Source and location in episode: [link and timestamp or passage]
- Comparison baseline, if used: [what is being compared]
- Episode topic: [what is this episode about]
- Key visual element: [what should dominate the thumbnail]
- Show brand colors: [hex codes or color names]
- Text overlay (if any): [maximum 5-7 words]

Requirements:
- Use only the supplied numbers; do not estimate missing values or invent a chart.
- Preserve units, dates and comparison context; ask for missing source details.
- Readable at 120x120px minimum
- High contrast between text and background
- Brand colors consistent with show identity
- Create the landscape YouTube video version at 16:9. Prepare podcast artwork separately for its destination.
```

Replace the bracketed placeholders with your specific details. The more context you provide about your audience, guest, and episode content, the better the output.

## Export and check

For landscape YouTube videos, use a 16:9 composition and the [current YouTube thumbnail specifications](https://support.google.com/youtube/answer/72431?hl=en). For [Apple Podcasts episode artwork](https://podcasters.apple.com/support/5516-episode-art-template), create a separate square image without text or the podcast logo, following Apple’s design recommendation. Check the destination rather than simply cropping the YouTube version.

Review the AI output against the supplied source yourself. Check the small-size preview, fix misleading text or image changes, and recheck before publishing.
