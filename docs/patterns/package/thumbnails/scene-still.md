# Scene Still

A thumbnail using a production still from the actual recording session. Choose it when the actual studio or recording moment is visually distinctive; avoid unremarkable or unprofessional frames.

**Stage:** Package → Thumbnails  
**Score:** 3  
**Evidence:** platform observation

## What It Is

A thumbnail using a production still from the actual recording session. Shows the studio, setup, or behind-the-scenes moment.

Select a frame from the actual recording that shows the distinctive setup or demonstration. Check screens, notes and background details for private information before making the crop.

## Example

Illustrative layout: use a real frame of a host demonstrating microphone placement, keeping the microphone and gesture visible. “Hear the difference” can accompany it if the episode actually compares the sound. A stock studio would not demonstrate this pattern.

## Quality Bar

- Readable at 120x120px minimum
- Maximum 5-7 words of text
- High contrast between text and background
- Brand colors consistent with show identity
- Face visible when using headshot or emotion styles

## When Not To Use

Avoid when the recording setup is not visually interesting or professional.

## Prompt Template

Copy and customize this prompt to generate this pattern:

```
Create a thumbnail using the Scene Still pattern.

Context:
- Actual recording still: [attach frame and source location]
- Detail to preserve in the crop: [equipment, gesture or scene]
- Permission and private-background check: [confirmed or unresolved]
- Episode topic: [what is this episode about]
- Key visual element: [what should dominate the thumbnail]
- Show brand colors: [hex codes or color names]
- Text overlay (if any): [maximum 5-7 words]

Requirements:
- Work from the attached real still; do not invent people, equipment or a studio.
- Omit or obscure private screens and notes without changing the demonstrated setup.
- Readable at 120x120px minimum
- High contrast between text and background
- Brand colors consistent with show identity
- Create the landscape YouTube video version at 16:9. Prepare podcast artwork separately for its destination.
```

Replace the bracketed placeholders with your specific details. The more context you provide about your audience, guest, and episode content, the better the output.

## Export and check

For landscape YouTube videos, use a 16:9 composition and the [current YouTube thumbnail specifications](https://support.google.com/youtube/answer/72431?hl=en). For [Apple Podcasts episode artwork](https://podcasters.apple.com/support/5516-episode-art-template), create a separate square image without text or the podcast logo, following Apple’s design recommendation. Check the destination rather than simply cropping the YouTube version.

Review the AI output against the supplied source yourself. Check the small-size preview, fix misleading text or image changes, and recheck before publishing.
