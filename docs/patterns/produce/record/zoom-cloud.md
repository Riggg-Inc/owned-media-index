# Zoom Cloud Recording

Recording a Zoom call using the cloud recording option, which saves files to Zoom's servers. Use it when local capture is unavailable or the recording is a meeting reference, not when the planned edit needs isolated participant video.

**Stage:** Produce → Record  
**Score:** 2  
**Evidence:** Practitioner observation

## What It Is

Recording a Zoom call using the cloud recording option, which saves files to Zoom's servers. Cloud recording can save active-speaker, gallery and shared-screen views as separate video files, plus separate participant audio when enabled. These views are not independent camera recordings of every participant.

## Why It Gets a 2

Zoom cloud recording is a **fallback, not our default for planned video production**. Speaker and gallery views limit independent framing in the edit. Choose isolated participant capture when you need that flexibility; choose cloud capture when the available views and audio pass a test for your intended deliverable.

## What You Get

| Output | Quality | Isolated? |
|---|---|---|
| Video (active speaker) | Depends on HD settings and meeting layout | ❌ Single mixed view |
| Video (gallery) | Depends on HD settings and meeting layout | ❌ Single mixed view |
| Audio | Compressed | ✅ Separate participant files when enabled |
| Transcript | Auto-generated when enabled | N/A |

## Setup and Quality Bar

1. Confirm recording permission and participant consent. Check that your licensed account has cloud recording enabled; an admin may control the settings.
2. In the Zoom web portal's Recording & Transcript settings, choose the speaker, gallery and screen views you need. Enable separate participant audio and audio transcription if required.
3. Make a short test recording, then inspect the downloaded files: can you hear each speaker clearly and make the edit you planned? Zoom documents 360p, 720p and 1080p configurations; do not assume a resolution from the feature name. Phone callers can share a single audio file.

For example, a content-led webinar may only need the slides and speaker view. An interview needing separate close-ups should use isolated participant capture instead.

## When To Use

- Meeting recordings that may be repurposed later (not planned production)
- Situations where local recording is not possible (restricted devices, IT policies)
- Capturing webinars where the primary value is the content, not the production quality

## When Not To Use

- Any show requiring per-person video isolation
- A planned edit that requires camera angles or source detail absent from the test recording
- When a suitable isolated recording platform is available and the deliverable needs independent participant framing
