# Spaced-Repetition Reflection in Multi-Day Events

## What It Is

A publishing/sequencing pattern for multi-day event content: at the start of each day (or each new content block), a designated recap voice restates and reflects on the prior day's key messages before new material is introduced. The recap is short, deliberate, and positioned as a bridge — not a filler segment.

## Best For

- Multi-day virtual or in-person events published as owned media.
- Conference or summit content repackaged into a sequenced release.
- Serialized educational or training programs where learning outcomes matter.
- Cohort-based programs that release content across multiple sessions.

## Why It Works

Learning and retention decay between sessions. Reopening a day with a structured recap of the prior day's core messages brings the audience's attention back to the through-line before new content lands. This spaced-repetition effect reinforces the key messages an event is built to deliver and reduces the "cold start" cost of each new day.

Assigning the recap to a designated voice (a host, chair, or resident expert) gives it authority and consistency, so it reads as intentional structure rather than a housekeeping recap.

## Required Elements

- A designated recap voice consistent across days.
- A short, scripted or semi-scripted recap of the prior day's key messages.
- Placement at the top of each day/block, before new content.
- A defined set of "key messages" per day that the recap can pull from.
- Tight runtime so the recap reinforces without re-teaching.

## Quality Bar

Each day should open with a recap that a returning audience member recognizes as the previous day's core takeaways, and that a new or lapsed viewer can use to get oriented. The recap should feel like a deliberate part of the program's structure, not an ad-lib summary.

## When Not To Use

- Single-session content with no day-over-day continuity.
- Programs where each session is fully standalone and shares no through-line.
- Formats where a recap would break pacing (for example, tightly edited highlight reels).
- Cases where no consistent recap voice is available across days.
